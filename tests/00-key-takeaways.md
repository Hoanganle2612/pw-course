# Toán tử chia hết
1. 3%0 = undefinded
2. 3%1 = 0 (3 chia hết cho 1 dư 0)
3. 3%2 = 1 (3 chia 2 = 1 dư 1)
4. 1%2 = 1 (1 không chia hết cho 2 dư 1)
5. 100%80 = 20 (100 dư 20 để chia hết cho 80)
6. 3%3 = 0 (3 chia hết cho 3 dư 0)
